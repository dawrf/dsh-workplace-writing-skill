# dsh-workplace-writing-skill

给 DeepSeek Harness（dsh）用的**职场专业写作技能（Skill）**：一份教 AI 怎么写职场文档的说明书。

装上之后，当你对 AI 说「帮我写个周报」「整理一份汇报材料」「给老板写封邮件」，AI 会自动翻开这本手册，按里面的规范产出：结论先行、用数据说话、按固定结构成文、文末不留出处。

## 覆盖的文档类型

| 类型 | 固定结构 | 默认字数 |
|---|---|---|
| 周报 / 月报 | 总览 → 完成 → 问题与风险 → 计划 → 需要的支持 | 300–600 字 |
| 工作总结 / 述职 | 结论 → 成果 → 方法 → 不足 → 规划 | 800–1500 字 |
| 汇报材料 / 讲话稿 / PPT 大纲 | 背景目标 → 进展 → 问题方案 → 决策需求 → 下一步 | 1500–2000 字 |
| 提案 / 方案 | 问题 → 目标 → 方案 → 风险对策 → 落地计划 | — |
| 商务邮件 / 公文 | 主题行 → 目的 → 背景 → 请求 → 落款 | — |

## 核心规则（七条总原则）

1. **结论先行**：开篇第一句就给结论。
2. **用数据说话**：能上数字就上数字，禁止「高度重视」「积极推进」这类空话。
3. **一段一事，动词开头**：条目以「完成/推进/输出」等动词开头。
4. **不编造**：缺数据用 `[待补充：...]` 占位，并在文末列出待补清单。
5. **短句**：一句话不超过 30 字。
6. **格式统一**：半角数字、统一单位、`YYYY-MM-DD` 日期、最多三层标题。
7. **文末不留出处**：不写「素材来源」「参考资料」（除非用户要求）。

## 安装

1. 找到你机器上的 dsh 用户技能目录（`skills` 文件夹，本仓库的 `workplace-writing` 目录就是从这里导出的）。
2. 把本仓库的 `workplace-writing` 文件夹整个复制进去。
3. 重启 dsh，新会话的技能列表里出现 `workplace-writing` 即生效。

## 目录结构

```
workplace-writing/
└── SKILL.md    # 技能本体：档案卡（name/description）+ 操作手册
```

## 如何定制

直接编辑 `SKILL.md` 即可，改完重启生效。想改默认字数、语气、禁用词，都在手册里一目了然。
